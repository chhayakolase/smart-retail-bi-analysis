# Smart Retail BI Analysis

## 📊 Project Overview

Smart Retail BI Analysis is a data analytics project focused on analyzing retail sales and profitability using Python, SQL, and Power BI.

The project transforms retail transaction data into meaningful insights to understand sales performance, profitability, product categories, and regional trends.

## 🎯 Objectives

- Analyze retail sales and profit performance
- Identify high-performing categories and regions
- Understand sales trends and business patterns
- Create visualizations for better decision-making
- Build an interactive Power BI dashboard
- Generate actionable business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Microsoft Excel
- Jupyter Notebook

## 🔍 Project Workflow

1. Collected and explored the retail dataset
2. Cleaned and prepared the data
3. Performed exploratory data analysis using Python
4. Analyzed sales and profit by category and region
5. Created data visualizations
6. Built an interactive Power BI dashboard
7. Generated business insights and recommendations

## 📁 Project Files

| File | Description |
|---|---|
| `Superstore_Analyst_final.ipynb` | Python data analysis notebook |
| `SampleSuperstore.csv` | Retail dataset |
| `Retail_Sales_Dashboard.pbix` | Power BI dashboard |
| `Retail_Sales_Profit_Analysis_Report.doc` | Project analysis report |

## 📈 Key Analysis Areas

- Sales analysis
- Profit analysis
- Category performance
- Regional performance
- Quantity analysis
- Sales trends
- Business insights

## 💡 Key Insights

The analysis helps identify changes in sales performance, profitable categories and regions, and areas where business strategies such as promotions or discounts can potentially improve performance.

## 🚀 How to Use

1. Download the repository.
2. Open `Superstore_Analyst_final.ipynb` using Jupyter Notebook.
3. Use `SampleSuperstore.csv` as the dataset.
4. Open `Retail_Sales_Dashboard.pbix` in Power BI Desktop to explore the dashboard.
5. Refer to the project report for detailed analysis and findings.
